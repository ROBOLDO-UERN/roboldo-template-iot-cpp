# 🔌 [TEMPLATE] Firmware IoT C/C++ (ESP32 / PlatformIO) — ROBOLDO

Template oficial da organização **[ROBOLDO-UERN](https://github.com/ROBOLDO-UERN)** para novos trabalhos de sistemas embarcados, IoT, sensores e controle de atuadores em **C/C++**.

## 🚀 Como usar este Template
1. Clique em **"Use this template"** -> **"Create a new repository"** na organização `ROBOLDO-UERN`.
2. O pipeline de **CI/CD** já está configurado para rodar análise estática (`cppcheck`) e compilar o firmware automaticamente com **PlatformIO** a cada Pull Request.
3. Vincule as tasks do projeto no **[Painel Geral da Organização (Project #6)](https://github.com/orgs/ROBOLDO-UERN/projects/6)**.
